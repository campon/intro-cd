# Tareas - Introducción a la Ciencia de Datos 2025 - Ignacio Campón & Mauro Loprete

Este repositorio contiene las soluciones de las tareas propuestas para la edición 2025 del curso de Introducción a la Ciencia de Datos realizada por los autores antes mencionados.

El procedimiento para correr los jupyter notebooks consiste en instalar los requerimientos agregados en requirements.txt de la siguiente forma:
```sh
cd ruta/a/introCD/tarea_1/
pip install -r requirements.txt
```
## Tarea 1

La carpeta *tarea_1* contiene:
 - **Tarea 1 - Introducción a la Ciencia de Datos.pdf** la letra de la tarea
 - **tarea1_campon_loprete.ipynb** un notebook con la realización de la misma para poder replicar lo realizado (contiene el paso a paso con comentarios y algunas lineas comentadas a modo de simplificar los prints)
 - **tarea1_campon_loprete.qmd** un archivo de extensión quarto con el cual es realizado el informe y compilado a *.pdf*
 - **tarea1_campon_loprete.pdf** el informe completo de la tarea 1, edición 2025
